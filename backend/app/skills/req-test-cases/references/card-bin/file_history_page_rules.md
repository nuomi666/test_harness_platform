# 卡BIN文件历史页面（file_history_page_rules）

> 本规则采用「编号条目」写法：第 4 章核心业务规则（R 编号）、第 5 章状态流转（S 编号）是生成用例的**必覆盖条目源**，每一条都必须产出对应用例（条数不低于该条「必生成数」），并在输出末尾的「编号覆盖自检表」中逐条打勾核对。第 1~3 章是给模型理解页面 UI 的背景信息，不承载必覆盖项。本页面**无表单输入字段**（均为按钮/状态操作），故不设字段约束表（F 表），规则集中到 R + S。
>
> ⚠️ 本页面版本状态共 **6 种**：生成中（XX/XXX）、生成失败、待发布、已发布、已过期。严格按下表「各状态对应操作」生成用例，不得漏配、错配。

## 1. 页面定位与数据流向

- **定位**：基于卡BIN池**有效（使用中）**数据生成对外发布的终端版本文件，供下游业务消费；支持新版本生成、历史版本查询、版本文件下载。
- **数据来源**：上游「卡BIN池管理」中状态为「使用中」的 BIN 记录（**仅纳入「使用中」，已弃用记录不参与**）。
- **数据消费**：生成的文件供终端按版本下载；版本发布后终端可收到新版本通知并自行决定下载时机。
- **本页面边界**：仅负责版本文件的生成、状态管理、下载；不涉及 BIN 数据维护（归上游池管理），不涉及文件导入/解析（归原数据文件历史）。

## 2. 页面元素清单

### 2.1 查询筛选区

| 控件 | 类型 | 名称 | 默认值 | 说明 |
|---|---|---|---|---|
| 输入框 | text | 版本号 | 空 | 模糊查询版本号 |
| 日期选择器 | date | 生成时间 | 空 | 范围查询（起止） |
| 下拉框 | select | 版本状态 | 全部 | 生成中 / 生成失败 / 待发布 / 已发布 / 已过期 |
| 按钮 | button | 重置 | - | 清空所有筛选条件，列表回到默认查询 |
| 按钮 | button | 查询 | - | 按当前筛选条件查询 |

### 2.2 操作区

| 控件 | 类型 | 名称 | 说明 |
|---|---|---|---|
| 按钮 | primary | 生成新版本 | 打开「生成新版本确认弹窗」，基于当前卡BIN池「使用中」数据生成 |

### 2.3 列表展示区

- **固定列**：版本号 | 生成时间 | 文件大小 | BIN记录数 | 与上版本差异 | 版本状态 | 操作
- **版本状态枚举（6 种，操作项随状态显隐）**：

| 版本状态 | 说明 | 可见操作 |
|---|---|---|
| 生成中（XX/XXX） | 版本文件正在编译生成中，完成后自动变为「待发布」 | 无 |
| 生成失败 ⚠️ | 版本文件生成失败 | 删除 |
| 待发布 | 版本文件已生成完成，等待运营确认发布 | 下载BIN文件 / 发布 / 删除 |
| 已发布 | 版本已发布，终端可下载 | 下载BIN文件 |
| 已过期 | 版本已被新版本替代 | 下载BIN文件 |

- **进度展示**：生成中状态值展示为「生成中（XX/XXX）」，XX 代表已生成成功的文件数，XXX 代表总共需要生成的文件数。
- **特殊标记**：当前生效版本（最新已发布）标注「(最新)」，同一时刻仅一条。
- **默认排序**：按生成时间倒序。

### 2.4 分页区

- 标准分页组件：每页条数切换、页码跳转、首页/末页快捷。
- **列表为空态**：
  - 无任何数据时：显示「暂无数据」占位图。
  - 筛选无结果时：显示「暂无数据」占位图。

## 3. 弹窗元素清单

### 3.1 生成新版本确认弹窗
- **标题**：生成新版本（带警告图标）
- **提示文案**：确认基于当前卡BIN池生成新的终端文件版本？
- **操作按钮**：取消、确定（主按钮）。

### 3.2 生成中拦截提示弹窗
- **标题**：生成新版本（带警告图标）
- **提示文案**：已存在生成中或待发布的版本记录，不允许生成新的版本！
- **操作按钮**：取消（仅单按钮，无确认入口）。

### 3.3 发布确认弹窗
- **标题**：发布（带警告图标）
- **提示文案**：确认发布当前版本吗？发布后终端将收到新版本通知，并自行决定下载时机。
- **操作按钮**：取消、确定（主按钮）。

### 3.4 删除确认弹窗
- **标题**：删除（带警告图标）
- **提示文案**：确认删除当前版本吗？
- **操作按钮**：取消、确定（红色危险主按钮）。

### 3.5 全局操作提示条
- **位置**：页面顶部。
- **样式**：绿色成功提示条，带关闭按钮。
- **文案示例**：新版本 v20260701-02 已开始生成，预计XX分钟后完成。

## 4. 核心业务规则（必覆盖条目，编号 R）

> 每条规则必须生成不低于「必生成数」的用例，并按「覆盖要求」列补齐各业务态（正向/异常/边界/状态）场景，缺一不可。

| 编号 | 规则 | 描述 | 等级 | 必生成数 | 覆盖要求 |
|---|---|---|---|---|---|
| R1 | 生成数据源 | 生成新版本基于当前卡BIN池**全量「使用中」数据**；「已弃用」记录不纳入 | P0 | 2 | 正向：生成的文件仅纳入「使用中」记录1条；状态：卡BIN池存在「已弃用」记录时不纳入1条 |
| R2 | 生成并发拦截 | 存在「生成中」或「待发布」版本时，点击「生成新版本」被拦截，弹出拦截提示弹窗（仅取消按钮，不可继续生成） | P0 | 2 | 正向：存在「生成中」版本时拦截1条；存在「待发布」版本时拦截1条。异常：拦截弹窗仅「取消」按钮，无确认入口 |
| R3 | 版本唯一性 | 同一时刻仅存在一个「已发布」且标注「(最新)」的当前生效版本 | P0 | 1 | 正向：任一时刻列表中「已发布(最新)」的唯一性成立1条 |
| R4 | 自动过期 | 新版本发布成功后，上一「已发布(最新)」版本自动变为「已过期」 | P0 | 1 | 状态：发布新版本后旧版本自动转「已过期」，最新标记迁移到新版本1条 |
| R5 | 差异计算 | 与上版本差异展示增减量（如 +88）；首个版本显示「--」 | P1 | 2 | 正向：第二个版本起显示增减量（符号正确）1条；边界：首个版本差异列显示「--」1条 |
| R6 | 版本号规则 | 版本号采用 vYYYYMMDD-N 格式；同一天多次生成 -01/-02 顺序递增，跨天重置为 -01 | P1 | 2 | 正向：同一天第二次生成版本号递增为 -02 1条；边界：跨天首次生成版本号为 -01 1条 |
| R7 | 生成中进度展示 | 生成中状态值展示「生成中（XX/XXX）」，XX=已成功文件数，XXX=总文件数 | P1 | 1 | 正向：生成中状态展示进度格式正确（XX/XXX 与实际进度一致）1条 |
| R8 | 文件一致性与下载 | 下载的BIN文件内容与生成时刻卡BIN池「使用中」数据完全一致；已发布版本文件内容不受后续数据变更影响 | P0 | 2 | 正向：下载文件内容与发布版本一致1条；状态：已发布后即使池数据变更，该版本文件内容不变1条 |
| R9 | 状态-操作联动 | 各版本状态展示对应操作集：生成中=无；生成失败=删除；待发布=下载/发布/删除；已发布=下载；已过期=下载 | P0 | 3 | 正向：生成中无任何操作1条；生成失败仅删除1条；待发布含下载/发布/删除三操作1条；已发布/已过期仅下载（各1条）。异常：非对应状态的按钮不得出现 |

## 5. 状态流转表（必覆盖条目，编号 S）

| 编号 | 状态流转 | 触发操作 | 前置 | 等级 | 覆盖要求 |
|---|---|---|---|---|---|
| S1 | 生成中 → 待发布 | 版本编译自动完成 | 存在1条「生成中」版本 | P0 | 正向：生成完成后自动转为「待发布」，生成中状态不再展示进度1条 |
| S2 | 生成中 → 生成失败 | 版本编译失败 | 存在1条「生成中」版本 | P1 | 正向：生成失败后状态显示「生成失败」及警告标识，该状态仅「删除」操作1条 |
| S3 | 待发布 → 已发布 | 发布（二次确认） | 存在1条「待发布」版本 | P0 | 正向：确认后状态转「已发布」，且上一版本自动过期1条；异常：二次确认「取消」→状态不变、弹窗关闭1条 |
| S4 | 已发布 → 已过期 | 被新版本替代（自动） | 存在1条「已发布(最新)」版本 | P0 | 状态：新版本发布后旧版本自动转「已过期」，最新标记迁移1条 |
| S5 | 待发布/生成失败 → 移除 | 删除（二次确认） | 存在1条「待发布」或「生成失败」版本 | P1 | 正向：确认后记录从列表移除，总条数减少1条；异常：二次确认「取消」→记录保留、弹窗关闭1条 |
