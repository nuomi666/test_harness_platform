# 卡BIN池管理页面（pool_page_rules）

> 本规则采用「编号条目」写法：第 4 章核心业务规则（R 编号）、第 5 章字段约束（F 编号）、第 6 章状态流转（S 编号）是生成用例的**必覆盖条目源**，每一条都必须产出对应用例（条数不低于该条「必生成数」），并在输出末尾的「编号覆盖自检表」中逐条打勾核对。第 1~3 章是给模型理解页面 UI 的背景信息，不承载必覆盖项。

## 1. 页面定位与数据流向

- **定位**：维护平台所有基础卡BIN数据，是生成终端使用的卡BIN文件的数据源。
- **数据来源**：
  - 手工创建：通过本页面「新增弹窗」录入。
  - 文件导入：由上游「卡BIN原数据文件历史」完成文件导入与解析后流入本池。
- **数据消费**：下游「卡BIN文件历史」基于本池数据按版本生成卡BIN文件（**仅纳入「使用中」记录**）。
- **本页面边界**：仅展示与维护两类来源的混合数据；不涉及文件导入/解析/冲突裁决操作（均归上游页面）。
