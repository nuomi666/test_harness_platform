# 卡BIN冲突裁决页面（含裁决详情页面）（conflict_resolution）

> 本规则采用「编号条目」写法：第 4 章核心业务规则（R 编号）、第 5 章状态流转（S 编号）是生成用例的**必覆盖条目源**，每一条都必须产出对应用例（条数不低于该条「必生成数」），并在输出末尾的「编号覆盖自检表」中逐条打勾核对。第 1~3 章是给模型理解页面 UI 的背景信息，不承载必覆盖项。
>
> ⚠️ 本文件覆盖**两个页面**，请按当前生成目标页面取对应规则，禁止混用：
> - **冲突裁决页面**（未裁决态，**可操作**）—— R1~R11（+ S1、S2）
> - **裁决详情页面**（已裁决态，**只读**）—— R12~R14
>
> ⚠️ 本页面**不是标准列表页**：**无查询筛选区、无独立分页组件**（冲突组列表以表格内滚动呈现）。因此通用规则（`page_common_rules.md`）中的「查询筛选区 / 重置按钮 / 分页组件」条目在本页面**不适用**；但「列表展示、状态标识、空数据、超长文本、二次确认、异常场景」等条目仍需覆盖。

## 1. 页面定位与数据流向

- **定位**：解决 FirstData 文件解析结果与卡BIN池「手工创建」记录之间的 BIN 范围冲突，由运营逐组决策，决定哪些记录最终进入卡BIN池。
- **上游**：「卡BIN原数据文件历史」——文件上传、解析、冲突检测。解析后检测到冲突时文件状态置「需人工处理」，从列表「冲突裁决」入口进入本页面（冲突裁决页）。
- **下游**：「卡BIN池管理」——确认裁决后按决策结果写入卡BIN池（保留手动 / 以FirstData覆盖）。
- **进入条件**：
  - 文件状态 =「需人工处理」→ 可进入**冲突裁决页**（可操作）。
  - 文件状态 =「已处理」且存在裁决记录 → 可进入**裁决详情页**（只读）。
  - 解析后**无任何冲突**的文件不进入本页面，由上游自动入库并置「已处理」。
- **数据范围**：每次裁决或查看详情均以**单个 FirstData 文件**为范围，只处理该文件解析结果与卡BIN池「手工创建」记录的冲突。
- **本页面边界**：仅负责冲突展示与裁决决策；不涉及文件上传/解析（归上游），不涉及 BIN 数据日常维护（归下游池管理）。

## 2. 页面元素清单

### 2.1 冲突裁决页（未裁决态，可操作）

#### 顶部提示区

- 「还有 X 项冲突未裁决」提示：**点击「确认裁决」且仍有未决策的冲突组时**弹出，X = 尚未决策的冲突组数量（详见 R9）。

#### 统计卡区（5 张）

| 卡片 | 口径 |
|---|---|
| 待裁决冲突组 | 冲突组总数（单位：组） |
| 冲突组内FirstData记录数 | 冲突组涉及的 FirstData 记录总数 |
| 冲突组内手动创建记录数 | 冲突组涉及的卡BIN池「手工创建」记录总数 |
| 无冲突记录 | 源文件中无冲突的记录数 |
| 源文件卡BIN记录数 | 该文件解析后**合并**的有效数据记录总数 |

- **口径恒等式**：无冲突记录 + 冲突组内FirstData记录数 = 源文件卡BIN记录数。
- **口径说明**：以上所有记录数均为**解析合并后**的数量，**非源文件原始行数**；与上游「卡BIN原数据文件历史」的「BIN记录数」定义一致（有效数据记录数 = 总记录数 − 2，再经相邻记录合并后的数量）。

#### 说明条（蓝色）

- 文案：「以FirstData为准（删除冲突手动创建记录）；保留手动为准（跳过冲突FirstData条目保留手动）；取消导入（放弃整个文件）。**每组决策将统一应用于组内所有记录，不支持逐条拆分。**」

#### 操作区

| 控件 | 类型 | 名称 | 说明 |
|---|---|---|---|
| 按钮 | button | 批量处理 | 下拉项：保留手动 / 以FirstData覆盖；**需先勾选冲突组**，未勾选点击时给出「请选择」弱提示（详见 R7） |

#### 冲突组明细列表（N 组）

- **固定列**：☑（复选框）| FirstData新记录 | 手动创建记录（现有）| 冲突原因 | 字段对比 | 决策操作
- **行粒度**：**一行 = 一个冲突组**；组内可能包含 1 条或多条 FirstData 记录、1 条或多条手动创建记录（详见 R4）。
- **`+N` 徽标**：表示该组内额外还有 N 条记录（可出现在 FirstData 侧或手动侧）。
- **冲突原因枚举**：被包含 / 包含 / 部分重叠（判定口径见 R3）。
- **字段对比**：点击该列图标打开「字段对比」弹窗（见第 3 章）。
- **决策操作**：单选「保留手动 / 以FirstData覆盖」；默认值见 R5；未点「确认裁决」前可随时更改（R6）。
- **列表为空态**：无冲突组时展示空状态占位（正常情况下有冲突才会进入本页面）。

#### 底部操作栏

| 控件 | 类型 | 名称 | 说明 |
|---|---|---|---|
| 按钮 | button | 返回 | 返回上游列表，未提交的决策不保存 |
| 按钮 | button | 取消导入 | 放弃整个文件导入（见 R11） |
| 按钮 | primary | 确认裁决 | 提交全部决策（见 R9 / R10） |

### 2.2 裁决详情页（已裁决态，只读）

- **结构**：文件名 → 统计卡 → 冲突组明细列表 → 裁决记录 → 底部「返回」。
- **统计卡**：5 张，口径与冲突裁决页一致，但首卡文案为「已处理冲突组」。
- **明细列表列**：FirstData新记录 | 手动创建记录（现有）| 冲突原因 | 字段对比 | 决策操作。
  - **无复选框**；「决策操作」以**文本**展示（保留手动 / 以FirstData覆盖），**不可修改**。
- **裁决记录**：展示裁决人姓名 + 裁决时间（精确到秒）。
- **底部操作栏**：仅「返回」。

## 3. 弹窗元素清单

### 3.1 字段对比弹窗

- **弹窗标题**：字段对比
- **列结构**：对比项 | FirstData…（基准）| …（手动侧）| 手动创建记录（现有）
  - 首列为字段名；同侧有多条记录时**并排多列**（如 FirstData1、FirstData2…；手动1、手动2…）。
- **行内容**：LowBin、HighBin、MinPanLen、MaxPanLen、CountryCode、CardType、ProductID、CardClass、EDCType、StarAccess、TokenBin、FSA、Prepaid、VisaProductSubType 等字段逐行对比。
- **不一致标记**：数据不一致的单元格**标红**（单元格级；同一属性可能存在多列不一致）。
- **决策操作**（**仅冲突裁决页**）：底部提供「保留手动 / 以FirstData覆盖」单选，点「确定」**回写**主列表该组的决策；裁决详情页的该弹窗为只读，无决策区。

### 3.2 取消导入确认弹窗

- **弹窗标题**：取消导入（带警告图标）
- **提示文案**：确认放弃整个文件？该文件所有记录（含无冲突记录）将不会写入卡BIN池。
- **操作按钮**：取消、确定（红色危险主按钮）。
- > 文案以实际设计为准，此处为规则推断。

### 3.3 确认裁决二次确认弹窗

- **弹窗标题**：确认裁决（带警告图标）
- **提示文案**：确认提交本次裁决结果？
- **操作按钮**：取消、确定（主按钮）。
- > 文案以实际设计为准，此处为规则推断。
