# 用例差异分析技能（Case Diff Analyzer）

## 一、技能定位
用于功能模块需求迭代、版本升级时的测试用例生命周期管理，自动完成新旧用例对比，减少人工梳理成本。

## 二、适用场景
1.  功能模块需求变更，评估回归测试范围
2.  版本迭代，生成新版基线用例
3.  识别下线功能对应的废弃用例
4.  识别新增功能对应的补充用例

## 三、输出规范
### 3.1 变更类型定义
| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 有效保留 | 逻辑无变化 | 直接沿用 |
| 待修改 | 规则/文案/步骤变更 | 更新内容后保留 |
| 废弃删除 | 功能/场景下线 | 从基线用例中剔除 |
| 全新新增 | 新功能/新场景 | 补充到基线用例 |

### 3.2 输出结构
1.  整体变更统计（数量维度）
2.  逐条变更明细表格（含变更说明、影响范围）
3.  合并后最终用例（可直接作为新版基线）

## 四、使用约束
1.  必须基于真实的新旧用例进行对比，不得编造用例
2.  变更说明必须与需求变更点一一对应
3.  页面展示类变更（弹窗、报错、文案）必须纳入待修改分类
